# 🏍️ Enduro Map

Мобильный офлайн-навигатор для эндуро и внедорожной езды, написанный полностью на смартфоне (Termux + Java + WebView).

## 🚀 Основные функции:
* **Офлайн-карты:** Кэширование просмотренных участков (Спутник, Топо, Грунт, Ночная).
* **Запись трека:** Автоматическая отрисовка маршрута по GPS.
* **Рисование маршрутов:** Возможность рисовать тропы вручную пальцем.
* **Менеджер маршрутов:** Сохранение, просмотр и удаление маршрутов.
* **Экспорт/Импорт GPX:** Обмен маршрутами с другими навигаторами.
* **SOS-кнопка:** Быстрая отправка координат в СМС.
* **Спутниковый HUD:** Отображение скорости, высоты, пройденного пути и точности GPS.

## 🛠️ Сборка
Проект собирается без Android Studio, с помощью Termux и скрипта `build.sh`.
